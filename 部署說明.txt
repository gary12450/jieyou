解憂夢幻島 公會網站 — 部署說明
=====================================

架構（與花非花 v2 相同）
-------------------------
  使用者瀏覽器 → GitHub Pages（只放網頁，不存資料）
              → Google Apps Script 網頁應用程式（API）
              → Google 試算表（真正的資料庫）

  檔案：
    index.html、css\、js\、assets\   網站本體（上傳到 GitHub Pages）
    js\config.js                       網站設定：後端網址、圖鑑類別、稀有度、來源選項
    backend\Code.gs                    後端程式（貼到 Apps Script）
    dev\                               本機測試用（模擬後端、自動測試），不需部署


一、建立後端（Google 試算表 + Apps Script）
-------------------------------------------
1. 到 Google 雲端硬碟新增一個空白試算表，名稱例如「解憂夢幻島公會資料」。

2. 試算表選單「擴充功能 → Apps Script」，把編輯器裡預設的程式全部刪掉，
   貼上 backend\Code.gs 的全部內容，按儲存。

3. 左側齒輪「專案設定」→ 最下方「指令碼屬性」→ 新增下列屬性：
     REGISTER_CODE    公會註冊碼（會員註冊時要輸入，自己訂，例如 Dream2026）
     ADMIN_USERNAME   一級管理者帳號（例如 admin）
     ADMIN_PASSWORD   一級管理者初始密碼（至少 6 碼）
   帳號只能用中英文、數字與 _ . -（2～20 字）。
   管理員「重置密碼」時會產生隨機臨時密碼，只顯示給管理員，再轉告本人。

4. 回到編輯器，上方函式下拉選「setup」→ 按「執行」。
   第一次會要求授權，依畫面允許即可。執行紀錄出現「setup 完成」就好了，
   試算表會多出 members、items、competitions、guilds、users 五個分頁。

5. （建議）函式下拉改選「seedItems」→ 執行，會寫入 6 筆預建圖鑑
   （內容見「預建資料與資料來源.txt」）。重複執行不會重複新增。

6. 右上「部署 → 新增部署作業」→ 類型選「網頁應用程式」：
     執行身分：我
     具有存取權的使用者：所有人
   按「部署」，複製「網頁應用程式網址」（結尾是 /exec）。


二、設定網站並上傳到 GitHub Pages
---------------------------------
1. 打開 js\config.js，把剛才的 /exec 網址填進 PROD_API_URL 的引號裡。

2. 在 GitHub 建立一個公開 repo，把整個資料夾上傳（至少要有 index.html、css、js、assets）。
   backend、dev 一起上傳也沒關係，裡面沒有正式環境的密碼。

3. repo 的「Settings → Pages」→ Source 選「Deploy from a branch」→ Branch 選 main、/（root）→ Save。
   一兩分鐘後就能用 https://<帳號>.github.io/<repo名稱>/ 開啟。


三、開站後的第一步
------------------
1. 用 ADMIN_USERNAME／ADMIN_PASSWORD 登入，馬上按「修改密碼」換掉初始密碼。
   改完後可以把 Apps Script 指令碼屬性裡的 ADMIN_PASSWORD 刪掉（只有 setup 建立帳號時用到）。
2. 在「成員清單」上方的「公會管理」新增公會名稱。
3. 到「圖鑑」補上遊戲內的食靈、時裝、作物、料理…（會員也能新增）。
4. 把網址和 REGISTER_CODE 註冊碼給公會成員，讓大家自己註冊、登記角色、勾選擁有的項目。
5. 需要幫手時，在「使用者管理」把信任的會員設為二級管理者。


四、權限一覽
------------
  訪客（未登入）：可看全部資料，不能改。
  會員：可新增成員、圖鑑、競賽紀錄；只能修改／刪除自己建立的。
  二級管理者：可修改／刪除所有人的資料、管理公會、一次設定「誰擁有」某項目。
  一級管理者：以上全部，加上使用者管理（建二級管理者、升降角色、重置密碼）。

  刪除都是「軟刪除」：資料列還在試算表，只是填了 deletedAt。
  要救回：到試算表該列，把 deletedAt、deletedBy 兩格清空即可。


五、之後要改程式
----------------
  改了 Code.gs：Apps Script「部署 → 管理部署作業 → 編輯（鉛筆）→ 版本選『新版本』→ 部署」。
                 不建新部署，網址才不會變。
  改了網頁（js、css、index.html）：重新上傳到 GitHub，約一兩分鐘生效；
                 瀏覽器有快取時按 Ctrl+F5 強制重新整理。
  要加圖鑑類別：改 js\config.js 的 CATEGORIES，加一行即可。


六、本機測試（不會動到正式資料）
--------------------------------
  需要 Node.js。雙擊專案資料夾裡的「本機測試.bat」，會自動啟動並開啟瀏覽器；
  黑色視窗要開著，關掉就停止。（已經在跑時再雙擊，只會開瀏覽器。）
  也可以在專案資料夾執行：
    node dev\server.js
  再用瀏覽器開 http://localhost:8140/
  在 localhost 開啟時網站會自動改連本機模擬後端（真正執行 backend\Code.gs，資料存在 dev\mock-db.json）。

  測試帳號：admin／test1234，註冊碼：test（設定在 dev\mock-config.json，僅供本機測試）
  清空模擬資料重來：node dev\server.js --reset
  後端自動測試：node --test dev\backend.test.js
